# AIFlow

Personal AI video generation tool — combines Google **Veo 3** (via Flow), **Gemini**, and **TTS** into one pipeline.

> Personal use only. Native Windows. Not a hosted service — it runs locally and
> drives your own logged-in Google Flow session through a Chrome extension.

## What it does

- **Input**: a start image + text prompt (working today via CLI), or — through the
  content adapters — product images, scripts, articles, documents, RSS, etc.
- **Output**: an MP4 generated by Veo 3, downloaded to `storage/output/`.

The smallest real end-to-end path that works today is:

```
start image + prompt  →  Veo 3 (image-to-video)  →  poll  →  final .mp4
```

run from the `aiflow gen-clip` CLI.

## How it works

```
┌──────────────┐   HTTP :8101 / WS :9223   ┌─────────────────────┐
│ Chrome +     │ <───────────────────────> │  AIFlow server      │
│ AIFlow Bridge│                            │  (FastAPI, Python)  │
│ extension    │  captures Bearer token     │                     │
└──────┬───────┘  from labs.google          │  - Flow SDK (Veo3)  │
       │                                     │  - Gemini client   │
       ▼                                     │  - TTS / Whisper    │
┌──────────────┐                             │  - Adapters        │
│ Google Flow  │   signed video request      │  - SQLite + storage│
│ (Veo 3)      │ <───────────────────────────┤                    │
└──────────────┘                             └─────────────────────┘
```

1. The **server** runs locally on `127.0.0.1:8101` (HTTP) and `:9223` (WebSocket).
2. The **Chrome extension** ("AIFlow Bridge") connects to the WebSocket, and when
   you open the Flow tab it captures your Google Bearer token + solves reCAPTCHA
   in the page context.
3. The server uses that token to submit Veo 3 generation requests and download
   the result — so you need an **active Flow Pro/Ultra subscription logged into
   Chrome**.

> The server binds to `127.0.0.1` only. There is **no authentication** on the
> local API because it is not exposed to the network. Do not port-forward it.

## Prerequisites

| Requirement | Notes |
|-------------|-------|
| **Python 3.12+** | 3.12 recommended (LMDeploy GPU TTS fast-path). 3.14 works for everything except LMDeploy. |
| **Google Chrome** (or Edge) | For the extension + Flow login. |
| **Google Flow Pro/Ultra** | $20/mo at [labs.google/fx/tools/flow](https://labs.google/fx/tools/flow). Required for Veo 3. |
| **Gemini API key** | Free tier at [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey). |
| **FFmpeg + ffprobe** | On `PATH`, or drop `ffmpeg.exe`/`ffprobe.exe` in `vendor/`. Needed for compose/remaster, not for `gen-clip`. |

## Install

```powershell
cd D:\Project\AIFlow\app

# 1. Create a virtual environment (3.12 preferred)
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
#   cmd.exe instead of PowerShell:  .venv\Scripts\activate.bat

# 2. Install the package + dev tools
pip install -e ".[dev]"
```

### Optional dependency groups

Install only what you need:

```powershell
pip install -e ".[audio]"      # edge-tts + faster-whisper (TTS + subtitles)
pip install -e ".[visual]"     # Playwright (visual-layer overlays)
pip install -e ".[content]"    # pypdf / python-docx / feedparser / Pillow (document/feed/photo adapters)
pip install -e ".[remaster]"   # yt-dlp + browser-cookie3 + gmssl (Bilibili/Douyin remaster)

# everything at once:
pip install -e ".[dev,audio,visual,content,remaster]"
```

> `gmssl` (in `[remaster]`) is what enables the native Douyin A-Bogus signing.
> Without it, remaster downloads fall back to yt-dlp automatically.

### Vendor binaries

`aria2c.exe` is bundled in `vendor/`. FFmpeg is resolved from `PATH` first, then
`vendor/`. To fetch/verify binaries:

```powershell
python scripts/download_vendor.py
```

## Configure (`.env`)

```powershell
copy .env.example .env
notepad .env
```

Only **one** value is strictly required to boot the server:

```dotenv
AIFLOW_GEMINI_API_KEY=AIza...        # required — server refuses to start without it
AIFLOW_FLOW_PLAN=Pro                 # Pro | Ultra
```

Useful extras (full list + comments in `.env.example`):

```dotenv
AIFLOW_LOG_LEVEL=INFO                # DEBUG for verbose troubleshooting
AIFLOW_FLOW_DEFAULT_ASPECT=9:16      # 9:16 | 16:9
AIFLOW_TTS_PRIMARY=vieneu            # vieneu | edge_tts
```

> The `.env` file is git-ignored. Never commit real keys.

## Load the Chrome extension

1. Open `chrome://extensions`.
2. Toggle **Developer mode** (top-right).
3. Click **Load unpacked** and select `D:\Project\AIFlow\app\extension`.
4. Pin the "AIFlow Bridge" extension so you can see its popup.

The popup shows **Disconnected** until the server is running, then **Connected**.

## Smoke test (verify everything works)

Start the server in one terminal:

```powershell
.venv\Scripts\Activate.ps1
python -m server.main
```

You should see it bootstrap the DB and start on `:8101` / `:9223`.

In Chrome, open [labs.google/fx/tools/flow](https://labs.google/fx/tools/flow)
and make sure you are logged in. The extension popup should flip to **Connected**
and capture your token.

Then, in a second terminal:

```powershell
.venv\Scripts\Activate.ps1

# Server config + Gemini reachability (no Flow needed)
python scripts/test_gemini.py

# Full Phase-0 acceptance (config, DB, server, extension, token, Gemini, Veo3 image)
python server/scripts/smoke_phase0.py
```

`smoke_phase0.py` prints a per-check ✅/❌ summary and exits non-zero if anything
fails — run it first to confirm the extension + token path is healthy before
generating video.

## Generate a real video

The working end-to-end path is the **`gen-clip`** CLI: one start image + one
prompt → one Veo 3 clip.

**Pre-flight** (all three must be true):
1. `python -m server.main` is running.
2. The Flow tab is open and the extension shows **Connected**.
3. Your Flow Pro/Ultra subscription is active.

Then:

```powershell
# Using the installed entry point
aiflow gen-clip `
  --prompt "A serene mountain lake at sunrise, cinematic, 4K" `
  --start-image path\to\start.png `
  --output storage\output `
  --aspect 16:9 `
  --quality fast

# Or as a module (identical):
python -m server.cli gen-clip --prompt "..." --start-image path\to\start.png
```

Options:

| Flag | Default | Notes |
|------|---------|-------|
| `--prompt` | (required) | Text prompt for Veo 3. |
| `--start-image` | (required) | Path to the first-frame image (PNG/JPG). |
| `--output` | `storage/output/` | Output directory. |
| `--aspect` | `9:16` | `9:16` or `16:9`. |
| `--model` | `VEO3` | `VEO3`, `VEO3_LITE`, `VEO3_QUALITY`. |
| `--quality` | `fast` | `lite` \| `fast` \| `quality`. |

The CLI waits for the extension + token, submits the request, polls every 5s
(up to ~10 min), then writes `video_<id>_<timestamp>.mp4` to the output dir and
records the job in SQLite (`storage/projects.db`).

**Don't have a start image?** This script generates one (solid-color PNG, no
extra deps), runs the full pipeline, and validates the MP4:

```powershell
python scripts/test_gen_clip.py
```

It downloads to `storage/output/test_gen_clip_<timestamp>.mp4`. Open it in a
player to review motion/quality (Veo 3 also generates ambient audio).

## Optional features

### Text-to-speech

```powershell
pip install -e ".[audio]"
python scripts/test_tts_smoke.py
```

Default voice is `Binh` (VieNeu, Vietnamese male) with `vi-VN-HoaiMyNeural`
(edge-tts) as fallback. The server exposes `GET /api/tts/voices` and
`POST /api/tts/synthesize` when running.

### Video remaster (Bilibili / Douyin → translated subs)

```powershell
pip install -e ".[remaster]"     # yt-dlp + gmssl + browser-cookie3
```

Native API downloads use real anti-bot signing (Douyin A-Bogus, Bilibili WBI)
and fall back to yt-dlp automatically. A live end-to-end run needs valid
platform cookies — verify offline first:

```powershell
python server/scripts/verify_video_remaster.py --local-file path\to\video.mp4 --preset light
```

### CapCut / SRT export

With the server running and a project that has scenes:

- `POST /api/projects/{id}/export/capcut` — build a CapCut draft.
- `GET  /api/projects/{id}/export/srt` — download subtitles.

## Troubleshooting

**Server won't start: `AIFLOW_GEMINI_API_KEY is required`**
→ Put a valid key in `.env`. Get one at aistudio.google.com/app/apikey.

**Extension popup stays "Disconnected"**
→ Start `python -m server.main` first. The extension polls
`http://127.0.0.1:8101/api/ext/discovery`; if the server isn't up it can't find
the WebSocket port.

**CLI hangs at "Waiting for Bearer token"**
→ Open [labs.google/fx/tools/flow](https://labs.google/fx/tools/flow) in the same
Chrome profile where the extension is loaded, and make sure you're logged in.
The token is captured from that page's requests.

**`gen-clip` fails with a quota / paygate error**
→ Confirm your Flow Pro/Ultra subscription is active and you have daily credits.

**Remaster download fails**
→ Install `[remaster]` and make sure `ffmpeg` is available. Without valid
platform cookies, login-walled videos will be rejected; supply cookies via the
extension or a Netscape cookie file (see `AIFLOW_COOKIES_SOURCE` in `.env`).

**FFmpeg not found**
→ Add `ffmpeg.exe`/`ffprobe.exe` to `PATH` or drop them in `vendor/`, or run
`python scripts/download_vendor.py`.
