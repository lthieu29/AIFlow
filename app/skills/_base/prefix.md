# Base skill prefix — prepended to every shot prompt

## Camera lock rules
Static locked-off camera. No handheld shake, no dolly, no pan, no tilt unless
explicitly specified in the scene motion hint. Stable tripod framing throughout.

## Safety rules
Photorealistic or illustrated style only. No real identifiable persons, no
copyrighted characters, no brand logos, no NSFW content, no violence, no
weapons. Subjects must appear fully clothed unless the scene explicitly
requires otherwise for artistic context.

## Continuity rules
Maintain consistent lighting direction, color temperature, and background
environment across consecutive scenes in the same location. When location
changes, a new visual style may be introduced but must remain internally
consistent within that location block.
