# Action-extreme — Character template

## Default archetypes
- A single named athlete-protagonist (parkour runner, stunt driver,
  fighter), three-quarter rear angle so face is partial.
- Optional opposing fighter / pursuer at the edge of frame.

## Identity anchors
- Wardrobe rig (jacket, harness, sash) consistent across the block.
- Choreography reads in two beats per clip; no chaotic mass action.

## Forbidden
- Real identifiable face. Branded sponsor gear.
- Live ammunition, gore, explicit injury.
- More than two combatants in frame at once.
