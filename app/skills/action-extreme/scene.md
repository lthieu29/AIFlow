# Action-extreme — Scene template

## Beat skeleton (typical 4-clip action set-piece)

| Beat       | Goal                                            | Typical shot |
|------------|-------------------------------------------------|--------------|
| chase      | tracking dolly behind protagonist               | wide tracking |
| obstacle   | low-angle hero leap / vault                     | medium hero |
| clash      | locked-off two-shot confrontation               | medium two-shot |
| breath     | the protagonist rises after the peak            | wide static |

## Per-scene composition rules

- One named environment per block (rooftop, alley, dojo, parking deck).
- Lens flare reserved for the peak beat only.
- Negative space at top for narrative caption later.

## Continuity across the block

- Same wardrobe, same rig, same lighting time-of-day.
- Audio sub-drop position consistent across the block.
