# Action-sports-pov — Character template

## Default subject
- A first-person athlete; only hands, board edges, ski tips, or
  handlebars in frame. No face.
- Optional supporting athlete in the background, partially obscured by
  motion blur.

## Identity anchors
- Hands gloved or rig-mounted across all clips.
- Same gear (helmet shape implied by lens flare, board colour, ski tip).

## Forbidden
- Real identifiable face. Branded gear visible. Sponsor logos.
- Third-person cuts, drone shots, off-the-helmet vantages.
