# Action-sports-pov — Scene template

## Beat skeleton (typical 4-clip POV reel)

| Beat       | Goal                                              | Typical shot |
|------------|---------------------------------------------------|--------------|
| approach   | rig moves toward the line / wave / corner         | locked POV |
| commit     | the action begins (drop / carve / push)           | locked POV |
| peak       | peak of the action (apex / barrel / launch)       | locked POV |
| landing    | wheels / skis / feet make contact, hold composure | locked POV |

## Per-scene composition rules

- Helmet horizon kept reasonably level except during bank.
- Hands or board edges visible in lower frame to confirm POV.
- Scenery rushes past consistently; do not slow without reason.

## Continuity across the block

- Same gear (gloves / helmet / board) across all clips.
- Same daylight hour and weather.
- Audio breath / wind sync continuous across cuts.
