# Cinematic Action — Character template

> Template used by the adapter to describe an action character.
> Each character gets a hard identity anchor reused across every scene so
> Veo3 i2v keeps the appearance consistent throughout the action sequence.

## Identity anchor (hard pin)

- **Name / alias**: {{NAME}}  (list aliases: {{ALIASES}})
- **Role**: {{ROLE}}  (hero / antagonist / ally / civilian)
- **Age range**: {{AGE}}
- **Build**: {{BUILD}}  (e.g. "athletic, broad-shouldered")
- **Hair**: {{HAIR}}  (style + color)
- **Signature wardrobe**: {{WARDROBE}}  (tactical gear, suit, street clothes)
- **Defining feature**: {{FEATURE}}  (one memorable trait for recognisability)

## Combat profile

- Fighting style: {{FIGHTING_STYLE}}  (e.g. "close-quarters, aggressive")
- Weapon / tool: {{WEAPON}}  (optional — firearm, blade, hand-to-hand)
- Movement signature: {{MOVEMENT}}  (e.g. "fast, explosive bursts")

## Framing per beat

- Establishing: low-angle wide shot showing full silhouette against dramatic sky
- Action: tight tracking shot following movement, shallow DOF on subject
- Reaction / impact: extreme close-up on face — sweat, determination, pain
- Hero moment: slow-motion low-angle, rim light outlining the figure

## Hard constraints

- No real identifiable persons; original fictional likeness only
- Live-action photorealistic look — no anime, cartoon, or illustration
- Keep identity consistent across all scenes (frontal neutral reference frame
  is the canonical anchor for i2v continuity)
- Violence must remain cinematic and non-gratuitous; no gore or explicit harm
