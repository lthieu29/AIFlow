# Cinematic Action — Scene template

> Template the adapter fills per shot when building action sequences.
> Each scene maps to one ~8s Veo3 clip. Camera is dynamic for this skill
> (manifest overrides the `_base` static default).

## Shot skeleton

- **Beat**: {{BEAT}}  (establishing / approach / confrontation / impact / aftermath)
- **Characters**: {{CHARACTERS}}  (refs to character.md identities)
- **Action**: {{ACTION}}  (one primary action — see motion.md vocabulary)
- **Location**: {{LOCATION}}  (urban_street / rooftop / warehouse / vehicle / outdoor_night)
- **Mood**: {{MOOD}}  (tense / explosive / desperate / triumphant / grim)
- **Time of day**: {{TIME}}  (drives lighting — night, dusk, harsh midday)

## Beat conventions

| Beat | Goal | Camera |
|------|------|--------|
| establishing | set location, threat level, stakes | wide low-angle, slow push-in |
| approach | build tension before confrontation | tracking follow, Dutch tilt |
| confrontation | face-off, standoff, or opening move | tight two-shot, rapid cut |
| impact | the decisive action moment | slow-motion, extreme close-up |
| aftermath | consequence, cost, or escape | wide pull-back or tight reaction |

## Continuity rules

- Maintain consistent lighting direction and color grade within a location
- Keep character wardrobe and appearance identical across scenes
- Use match-cut on motion for seamless action continuity
- Leave space for lower-third overlays at scene transitions
- Slow-motion beats should resolve within the 8s clip window
