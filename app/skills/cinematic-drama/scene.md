# Cinematic-drama — Scene template

## Beat skeleton (typical 4-clip drama excerpt)

| Beat       | Goal                                              | Typical shot |
|------------|---------------------------------------------------|--------------|
| setup      | wide of the room, lead enters, daylight motivated | wide static |
| dialogue   | medium two-shot at the table                      | medium 2-shot |
| reaction   | close-up of the lead's face, single tear          | extreme close-up |
| exit       | dolly out from face to room, leaves silence       | wide static |

## Per-scene composition rules

- Single named light source per shot (window / lamp / candle).
- Earth-tone palette held across the entire block.
- One prop per shot is the silent witness (clock, kettle, photo frame).

## Continuity across the block

- Same room, same lamp, same costume, same makeup.
- When the location changes (kitchen → bedroom), justify it in the script
  beat; do not jump arbitrarily.
