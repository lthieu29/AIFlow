# Dialogue-interview — Character template

## Default archetype
- A single named guest (chef, academic, artist, scientist, teacher).
- Photoreal but no real identifiable face.
- Single chair / desk / studio backdrop, neutral wardrobe.

## Identity anchors
- Wardrobe and hairstyle stable across all clips.
- Same chair, same backdrop, same lighting block.

## Forbidden
- Real identifiable face. Real branded backdrop. Sponsor products
  visible. Teleprompter screen showing.
