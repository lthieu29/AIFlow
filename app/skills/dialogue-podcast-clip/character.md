# Dialogue-podcast-clip — Character template

## Default archetypes
- Host: horn-rim glasses, casual sweater, headphones around the neck.
- Guest: casual blazer, simple shirt, unbranded coffee mug.

## Identity anchors
- Same wardrobe and headphones across all clips.
- Same mic placement on the desk.

## Forbidden
- Real identifiable face. Real podcast network branding.
- Real branded microphones (Shure, Rode logos visible).
- Burned-in captions in the video itself.
