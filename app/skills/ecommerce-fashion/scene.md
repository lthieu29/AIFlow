# Ecommerce-fashion — Scene template

> Template the adapter fills per shot. Each scene maps to one ~8s Veo3 clip.

## Shot skeleton

- **Beat**: {{BEAT}}  (hook / feature / proof / CTA)
- **Subject**: {{SUBJECT}}  (product alone, or model wearing product)
- **Action**: {{ACTION}}  (single clear action — see motion.md vocabulary)
- **Background**: {{LOCATION}}  (studio seamless, retail, or lifestyle indoor)
- **Framing**: knees-up when product is worn; tight detail for fabric/texture

## Beat conventions

| Beat | Goal | Typical duration |
|------|------|------------------|
| hook | grab attention in first 3s | 8s |
| feature | show product detail / material | 8s |
| proof | demonstrate fit / use in context | 8s |
| CTA | call to action, price anchor | 6–8s |

## Composition rules

- One product focus per scene — no clutter
- Locked-off static frame (camera lock inherited from `_base`)
- Leave headroom for lower-third / product-card overlays
- Keep continuity: same model, wardrobe, and lighting as adjacent scenes
