# Ecommerce-home — Character template

> Most home product clips are object-only. When a person is shown
> the description below applies.

## Default model archetype
- Hands or torso only when interacting with furniture, ceramics, textiles.
- Casual loungewear in muted earth tones to match the palette.
- Single person per scene; no group shots, no twins.

## Identity anchors
- Same hand / sleeve across the beat block.
- Hairstyle, sleeve length, and skin tone consistent across consecutive
  scenes within the same room.

## Forbidden
- No real identifiable face. No branded clothing logos visible. No
  recognisable family photos in the background.
