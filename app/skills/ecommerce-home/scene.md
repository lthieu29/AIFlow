# Ecommerce-home — Scene template

> Each scene = one ~8s Veo3 clip.

## Beat skeleton (typical 4-clip home ad)

| Beat       | Goal                                          | Typical shot |
|------------|-----------------------------------------------|--------------|
| context    | wide of the styled room corner with product   | wide static |
| feature    | named feature (linen weave, oak grain, glaze) | macro close-up |
| use        | hand or torso interacts with the product      | medium close |
| payoff     | hero with warm window light + props in place  | medium static |

## Per-scene composition rules

- Pick a single room palette per beat block (warm cream, sage, terracotta).
- Maximum 3 prop layers around the hero (book / mug / plant).
- Daylight direction fixed per block; do not shift sun midway.
- Negative space on one side of the frame for lower-thirds later.

## Continuity across the block

- Same room, same window, same plant.
- When location changes, restart the prop set and lighting block cleanly.
