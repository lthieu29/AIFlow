# Ecommerce-tech — Scene template

> Template the adapter fills per shot. Each scene maps to one ~8s Veo3 clip.

## Shot skeleton

- **Beat**: {{BEAT}}  (hook / feature / detail / proof / CTA)
- **Subject**: {{SUBJECT}}  (product alone, or hands interacting with product)
- **Action**: {{ACTION}}  (single clear action — see motion.md vocabulary)
- **Background**: {{LOCATION}}  (dark studio, gradient sweep, or lifestyle desk setup)
- **Framing**: tight detail for ports/buttons/screen; wide for full product silhouette

## Beat conventions

| Beat | Goal | Typical duration |
|------|------|------------------|
| hook | reveal product with dramatic lighting | 8s |
| feature | highlight key spec or design element | 8s |
| detail | macro shot of port, button, or finish | 8s |
| proof | demonstrate product in use (typing, tapping, plugging in) | 8s |
| CTA | price anchor, call to action, product name | 6–8s |

## Composition rules

- One product feature per scene — no clutter
- Locked-off static frame (camera lock inherited from `_base`)
- Dark background to make product pop; gradient sweep for premium feel
- Leave headroom for lower-third / product-card overlays
- Keep continuity: same lighting setup and background across adjacent scenes
