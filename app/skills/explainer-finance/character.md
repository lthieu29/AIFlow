# Explainer-finance — Character template

## Default archetype
- Analyst presenter: dark blazer, simple shirt, neutral tie, neat hair.
- Optional academic guest: softer sweater, wire glasses.
- Single subject in frame; data/charts as the secondary subject.

## Identity anchors
- Wardrobe and hairstyle stable across the block.
- Same desk / standing-set across the block.

## Forbidden
- Real identifiable face. Real ticker symbols visible.
- Real bank / brokerage branding. Specific buy / sell tickers.
