# Explainer-finance — Scene template

## Beat skeleton (typical 4-clip finance explainer)

| Beat       | Goal                                              | Typical shot |
|------------|---------------------------------------------------|--------------|
| hook       | presenter states the question                     | medium close-up |
| context    | brief historical / macro framing                  | medium close-up |
| chart      | a single chart with one named data point          | extreme close-up + push-in |
| takeaway   | presenter restates the takeaway                   | medium close-up |

## Per-scene composition rules

- Single named cool-light backdrop per block.
- One chart per scene; do not crowd the screen with multiple plots.
- Negative space top of frame for caption / network bug in post.

## Continuity across the block

- Same wardrobe, same desk, same backdrop.
- Audio bed pad continuous across cuts.
