# Explainer-history — Character template

## Default archetypes
- Scholar / curator: muted-tone jacket, glasses, gloved hand for handling
  artefacts.
- Period re-enactor: era-appropriate wardrobe (Roman tunic, medieval
  robe, Tang-dynasty silk).

## Identity anchors
- Same gloves and gallery space across the block for the scholar.
- Same period costume across the re-enactment block.

## Forbidden
- Real identifiable face. Real museum branding visible.
- Anachronistic props on re-enactment subjects.
- Nationalist propaganda imagery.
