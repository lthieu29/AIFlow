# Explainer-tech — Character template

> Template used by the adapter to describe a presenter or on-screen guide
> for tech explainer content. Keep faces neutral and non-identifiable.
> Characters serve as visual anchors for the educational narrative.

## Identity anchor (hard pin — reused across every scene)

- **Role**: {{ROLE}}  (presenter / narrator / on-screen guide)
- **Build**: {{BUILD}}  (e.g. "average build, professional posture")
- **Hair**: {{HAIR}}  (e.g. "short dark hair, neat")
- **Wardrobe**: {{WARDROBE}}  (clean tech-casual — plain t-shirt or collared shirt, no logos)
- **Expression**: engaged, focused, approachable — slight forward lean when explaining
- **Skin/makeup**: natural, clean, well-lit

## Framing defaults

- Medium close-up for direct-to-camera explanation segments
- Over-the-shoulder framing when pointing at a screen or diagram
- Hands visible and active — gesturing toward the subject being explained

## Hard constraints

- No real identifiable persons; original fictional likeness only
- No brand logos or copyrighted interface elements
- Identity must stay consistent across all scenes (same presenter, same wardrobe)
- Frontal neutral reference frame is the canonical anchor for i2v continuity
- Presenter should never obscure the product, screen, or data being explained
