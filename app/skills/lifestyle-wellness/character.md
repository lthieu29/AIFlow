# Lifestyle-wellness — Character template

## Default subject
- A practitioner: hand pouring tea, bare feet on a mat, calm exhale.
  Face partial / off-frame; never full identifiable face.
- Optional plant, candle, journal as silent companion subjects.

## Identity anchors
- Same wardrobe / mat / towel across all clips.
- Same lighting block; sunrise hour preserved.

## Forbidden
- Real identifiable face. Real branded apparel.
- Weight-loss before / after framing.
- Extreme contortion poses (out of skill scope).
