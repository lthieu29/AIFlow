# Product-tech-launch — Character template

> Hero tech launches are device-only by default. When a hand or
> presenter is shown the description below applies.

## Default subject (no human)
- One hero device against negative space, oriented at three-quarter angle.
- Single named accent colour (blue, orange, magenta) reserved for the
  screen content; chassis is graphite or brushed aluminium.

## Optional presenter
- Hands only, dark sleeve, neutral skin tone — no face.
- Hands enter and exit the frame from one side only per beat block.

## Forbidden
- Real identifiable face, branded shirt, real watch dial visible.
- Multiple devices on screen at once during the hero reveal.
