# Product-tech-launch — Scene template

> Each scene = one ~8s Veo3 clip. Hero device + controlled motion.

## Beat skeleton (typical 4-clip launch reel)

| Beat       | Goal                                                  | Typical shot |
|------------|-------------------------------------------------------|--------------|
| tease      | silhouette / partial reveal in negative space         | wide hero |
| reveal     | full device against backdrop with key + rim light     | wide hero with orbit |
| feature    | named feature: lens, hinge, port, screen detail       | extreme close-up |
| payoff     | hero locked-off with tagline read on Audio:           | wide hero |

## Per-scene composition rules

- One hero device per shot — no comparison shots, no accessories cluster.
- Negative-space backdrop chosen once for the whole reel.
- Single accent colour reserved for screen content.
- Specular highlights on a single edge per shot, never on every face.

## Continuity across the block

- Same backdrop, same key-light direction, same chassis colour.
- Synth swell continues across consecutive scenes; cue the lock on payoff.
