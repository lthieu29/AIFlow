# Social-viral-meme — Character template

## Default subject
- Single relatable scenario subject (desk worker, cat owner, gym goer).
- Face partial / off-frame; reaction conveyed by body language.
- One prop in frame that triggers the punchline.

## Identity anchors
- Same prop and pose across the punchline beat.
- Same lighting block; punchline is in body language, not light shift.

## Forbidden
- Real identifiable face. Branded clothing or props.
- Mockery of protected groups, religions, ethnicities.
