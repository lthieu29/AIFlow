# Social-viral-pet-comedy — Character template

## Default subject
- A single named pet (cat, dog, chinchilla, parrot, rabbit).
- Optional human: hand or torso only, no face.
- The pet is calm, healthy, and centered in frame.

## Identity anchors
- Same pet across all clips of the block.
- Same collar / harness / cage.

## Forbidden
- Real human face. Real branded leash / collar.
- Distressed animal behaviour. Training-collar shock moments.
