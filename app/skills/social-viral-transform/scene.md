# Social-viral-transform — Scene template

## Beat skeleton (typical 2-clip transformation)

| Beat       | Goal                                                  | Typical shot |
|------------|-------------------------------------------------------|--------------|
| before     | locked-off medium hero, mess / dull / cluttered state | medium static |
| after      | same vantage, transformed subject, same lighting      | medium static |

## Per-scene composition rules

- Identical framing before and after.
- Same backdrop, same hour of day.
- The transformation is achieved on the subject — never via swapped
  set dressing.

## Continuity across the block

- Mirror composition between before and after.
- Cut sound effect aligned to the beat drop.
